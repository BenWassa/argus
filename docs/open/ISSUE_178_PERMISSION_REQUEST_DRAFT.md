## Proposed-use text

I request written permission to reproduce current Canadian Armed Forces rank-insignia artwork in Argus, an independently developed educational progressive web app at https://argus-b7a5a.web.app, with public source at https://github.com/BenWassa/argus.

The proposed programme teaches recognition of one current canonical service-dress rank exemplar for each of 19 practical levels in each of the Canadian Army, Royal Canadian Navy and Royal Canadian Air Force: 57 scored reference images. It does not represent professional qualification, military affiliation or DND/CAF endorsement.

The requested works are the 57 exact source image URLs listed in the accompanying inventory, from the official Army, Navy and Air Force rank pages, controlled by Dress Instructions Figures 3-2-1, 3-2-3, 3-2-5, 3-2-6, 3-2-7 and 3-2-8. Navy officer examples use sleeve lacing. Please advise if any source artwork should be replaced before use.

Please confirm whether permission covers reproduction within the public PWA, browser installation and offline caches, and public redistribution of both approved originals and optimized derivatives through the public GitHub repository. Proposed transformations are resizing, proportion-preserving crop/padding for reference cards and conversion to web image formats. We request no permission to change insignia meaning or design.

Please specify permitted attribution, non-affiliation wording, territory, duration, commercial-use restrictions, revocation requirements and whether permission extends to subsequent officially published Canadian Royal Crown replacement artwork. If public repository redistribution or any transformation is excluded, please state those limits explicitly so the delivery design can be assessed before any reproduction.
