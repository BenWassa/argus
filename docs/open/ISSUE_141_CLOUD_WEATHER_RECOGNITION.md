# Issue #141 — Cloud and weather recognition programme

**Status:** research ready  
**Priority:** P0  
**Issue:** #141  
**Related:** #131 WMO cloud genera visual guide  
**Roadmap:** `docs/LIBRARY_ROADMAP.md`  
**Method:** `docs/LIBRARY_RESEARCH_METHOD.md`

## Purpose

Define a compact, accurate visual-recognition programme for clouds and basic weather interpretation, with real/source-controlled imagery preferred wherever practical.

## Owned research

- ten WMO cloud genera as likely foundation;
- visual distinctions and altitude/development groupings;
- exemplar diversity needed before visual recognition can be scored honestly;
- selected weather-change interpretation only where authoritative sources support it;
- possible later fronts/weather-map-symbol topics;
- image sourcing, licensing, AI fallback and QA.

## Current owner direction

- Cloud/weather recognition is a high-interest expansion area.
- Wikimedia Commons or other reusable real imagery is preferred when identity/licensing can be verified.
- AI-generated imagery is acceptable as fallback, but accuracy is gating.
- The content should help the learner read the environment, not overstate forecasting ability.

## Research contract

Use the required note structure in `LIBRARY_RESEARCH_METHOD.md`.

The research must finish with:

1. build/revise/defer decision for each proposed topic;
2. exact completion claims and exclusions;
3. source hierarchy and claim ledger;
4. visual characteristics to teach;
5. image-source/licensing ledger approach;
6. minimum exemplar-count/diversity recommendation;
7. AI-generation fallback and QA rubric;
8. relationship to #131 and shipped Beaufort material;
9. smallest reusable visual-stimulus primitive, if justified;
10. bounded implementation issues to open next.

## Key decision points

- whether cloud genera alone should ship first;
- how much natural visual variability must be represented;
- when one exemplar is reference-only versus sufficient for testing;
- which weather implications are defensible and which remain too context-dependent;
- whether #131 proceeds unchanged, is expanded, or is superseded after research.

## Non-goals

No professional meteorology claim, no advanced cloud taxonomy by default, no generated image accepted because it merely looks plausible, and no implementation inside this research issue.

## Handoff status

#131 should remain downstream until this research fixes the visual dataset and competency boundary.
