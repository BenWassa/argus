# Issue #138 — Maritime visual literacy

**Status:** research ready  
**Priority:** P0  
**Issue:** #138  
**Roadmap:** `docs/LIBRARY_ROADMAP.md`  
**Method:** `docs/LIBRARY_RESEARCH_METHOD.md`

## Purpose

Define the first coherent Maritime library programme for Argus using authoritative Canadian/international sources and phone-first visual learning.

## Owned research

- minimum vessel orientation/terminology prerequisite;
- navigation lights and aspect/viewing logic;
- selected day shapes;
- selected high-value International Code of Signals flags;
- media/provenance/QA approach for all visual material.

## Current owner direction

- This is a high-priority expansion area.
- Bow/stern/port/starboard and related terminology should support later visual reasoning rather than exist as isolated trivia.
- Navigation lights have strong potential when the learner must reason about vessel orientation and visible aspects.
- Signal flags should expand beyond a token example, but the retained set should be chosen for usefulness and authority rather than completeness for its own sake.
- Accuracy matters more than visual drama.

## Research contract

Use the required note structure in `LIBRARY_RESEARCH_METHOD.md`.

The research must finish with:

1. build/revise/defer decision for each proposed topic;
2. exact completion claim and exclusions;
3. source hierarchy and claim ledger;
4. scored item inventory/count;
5. Learn-only material;
6. visual/media plan and provenance/licensing rules;
7. QA method for diagrams/assets;
8. smallest required Argus product primitive;
9. bounded implementation issues to open next.

## Key decision points

- exact prerequisite vocabulary;
- which light configurations belong in a beginner scope;
- whether viewing-angle exercises require deterministic SVG/React;
- which day shapes add enough value for Level I;
- which single-letter signal flags deserve retained recall;
- whether any sourced assets can be used directly or should be redrawn from standards.

## Non-goals

No boating certification claim, tactical vessel operations, broad seamanship course, or implementation inside this research issue.

## Handoff status

No implementation issue should be opened until the research produces a finite, source-backed specification.
