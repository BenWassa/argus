## Executive decision

The next Argus expansion should move decisively toward **practical human-systems skills** rather than more symbol systems.

The first research pass produced several valid topics, but too many shared the same learning shape: memorize a vocabulary, mapping or code. That would create breadth on paper without much breadth of capability.

A more useful Argus library can include finite, defensible training in:

- situational awareness and environmental observation;
- separating observation from inference;
- anomaly detection and continuous reassessment;
- behavioural threat recognition without profiling;
- de-escalation and conflict communication;
- crisis active listening and rapport-building;
- psychological first aid;
- interviewing and witness-memory fundamentals;
- bias-aware judgement and deception-detection limits;
- evidence continuity and objective reporting;
- Canadian firearm safety and legal-memory support.

The important product change is not a new category label. It is a second learning shape.

Argus currently excels at **finite recall**. Many of the skills above require **finite knowledge plus scenario application**. They should therefore become the main candidates for a reusable scenario-practice capability, while retaining a narrow scored completion claim.

The recommended direction is:

> **Build a “field and human skills” family around observation → assessment → communication → escalation, with Ontario/Canadian source material where authoritative local material exists. Keep real-world practical competence distinct from app completion.**

For firearms, Argus should be a **memory and legal/safety companion** to the Canadian Firearms Safety Course and supervised hands-on training. It should not teach tactical weapon employment, marksmanship, room clearing, engagement tactics, or substitute for required licensing/training.

---

# 1. What changed from the first research pass

The first pass correctly enforced finite boundaries, sourceability, durability and honest completion claims. Those rules remain.

What it got wrong was the portfolio balance.

A library made of NATO extensions, SI prefixes, Greek letters, hexadecimal mappings, signal flags and similar material would become increasingly good at one narrow thing: **symbolic recall**.

That is useful, but it is not the strongest expression of the owner's stated goal: practical, retainable competence that can be used in real situations.

The better portfolio question is not:

> What other closed lists can Argus memorize?

It is:

> What practical judgements or behaviours can be decomposed into a finite body of knowledge, rehearsed safely in scenarios, and described honestly when completed?

That opens a much richer set of subjects.

# 2. New admission doctrine for practical skills

The original finite-topic gates still apply, with three additions.

## 2.1 Knowledge boundary

The course must state the exact knowledge or judgement being tested.

Example:

> Can distinguish direct observations from interpretations and produce an objective incident description containing time, location, actions and observable details.

This is testable.

By contrast:

> Has good street awareness.

is not a valid completion claim.

## 2.2 Application boundary

If the useful skill is situational, Argus must include scenario practice rather than pretending that card recall proves application.

The application exercise can still be finite and authored:

1. present a scenario;
2. expose a bounded set of observations;
3. ask the learner to classify, prioritize or select a response;
4. compare the answer to a source-backed rubric;
5. explain why alternatives were weaker;
6. repeat with changed details.

This is fundamentally different from trivia.

## 2.3 Reality boundary

Completion must not imply certification or field competence that the app cannot observe.

For example:

- **valid:** “can recall and apply the eight FBI active-listening techniques in authored scenarios”;
- **invalid:** “is a trained hostage negotiator.”

Likewise:

- **valid:** “can recall ACTS/PROVE and current federal storage/transport rules covered by the topic”;
- **invalid:** “is competent to handle firearms safely.”

Hands-on competence remains external.

# 3. The portfolio should become six capability families

## 3.1 Situational awareness and observation

This should be the foundation.

Ontario's current security-guard syllabus explicitly includes observing the physical environment, attending to environmental details, situational awareness, establishing a benchmark for later observations, identifying hazards, assessing behaviours and continually evaluating the situation. The Ontario private-investigator curriculum goes further: recognizing typicality, detecting anomalies, maintaining vigilance, recording accurate details and consistently re-evaluating conditions.

This is unusually good source material for Argus because it is local, practical and already designed as trainable knowledge.

Recommended course sequence:

### A. Situational awareness I — baseline, anomaly, reassess

**Completion claim**

> Can establish an environmental baseline, identify meaningful departures from it, and explain why reassessment is continuous rather than a one-time scan.

**What Learn teaches**

- baseline/typicality;
- anomaly as a deviation, not automatically a threat;
- environment, people, movement, access/egress and hazards;
- reassessment when conditions change;
- avoiding stereotype-based “suspicion.”

**Practice**

Show authored street, transit, office and venue scenarios. Ask:

- What is directly observable?
- What appears unusual relative to the stated baseline?
- Which change matters for safety?
- What additional information would reduce uncertainty?

The learner should sometimes be rewarded for answering **“insufficient information”**. That is important. Good situational awareness is not hypervigilance.

### B. Observation versus inference

This could become one of Argus's most useful psychology-adjacent topics.

**Completion claim**

> Can separate directly observable facts from interpretations, motives and unsupported conclusions.

Examples:

- observation: “He looked at the exit three times in two minutes.”
- inference: “He was planning to flee.”

The second may ultimately be right, but it is not what was observed.

This skill improves threat assessment, interviewing, consulting, reporting and ordinary decision-making.

**Practice**

Give short scenes and require classification into:

- observation;
- reasonable inference;
- unsupported inference;
- missing information.

### C. Objective incident description

Ontario's security and private-investigator material repeatedly emphasizes accurate, concise, bias-free reporting and recording time, place, actions and observable details.

**Completion claim**

> Can produce an objective short incident report that separates observable facts from conclusions and includes the essential chronology.

This is a natural field exercise and a practical writing skill rather than a vocabulary deck.

## 3.2 Behavioural threat recognition

This area is useful but must be designed carefully.

The central rule is:

> **Behavioural threat assessment is not profiling, diagnosis, or prediction.**

Current FBI behavioural-threat material explicitly warns that no single behaviour means a person is moving toward targeted violence, that many non-offenders may show similar behaviour, and that warning behaviours should be considered in context. Professional BTAM is multidisciplinary and case-management oriented.

Argus therefore should not teach “spot a dangerous person.” It can teach a narrower and more defensible skill: **recognize concerning behavioural patterns and choose an appropriate reporting/escalation response**.

### D. Threat recognition I — concern, context, escalation

**Completion claim**

> Can distinguish ordinary risk factors from dynamic warning behaviours, identify why no single sign predicts violence, and select an appropriate reporting/escalation level in authored scenarios.

Core concepts:

- no demographic or personality “profile”;
- behaviour and context over appearance;
- risk factors versus dynamic warning behaviours;
- concerning communication, leakage, fixation, material changes in behaviour and approach behaviours;
- totality of circumstances;
- multiple indicators matter more than isolated traits;
- report concerning behaviour rather than personally confronting a potentially dangerous person;
- imminent danger is an emergency-response problem, not an assessment exercise.

### E. Pathway to intended violence — conceptual model

The FBI's current Pathway to Intended Violence materials describe a progression from grievance/violent ideation through research/planning and preparation toward implementation. The value for Argus is recognition of **escalation structure**, not operational detail.

**Completion claim**

> Can explain the broad stages of the pathway-to-intended-violence model and distinguish movement toward implementation from a static grievance alone.

This topic should deliberately omit operational attack-method detail.

### F. Bias control in threat judgement

This is essential if Argus teaches threat recognition.

Ontario's private-investigator curriculum explicitly links ethical decision-making to recognizing patterns, typicality, anomalies, discrimination, prejudice and stereotyping.

A short course should rehearse:

- confirmation bias;
- anchoring on first impressions;
- stereotype substitution;
- availability after a recent alarming event;
- interpreting ambiguous behaviour as intent;
- overconfidence from “body-language” folklore.

The completion claim should be about identifying judgement errors, not becoming “objective.”

# 4. De-escalation and crisis communication

This should be the strongest candidate for a true Argus micro-curriculum.

Ontario's current security-guard training requires active listening, adaptation of communication style, verbal and non-verbal feedback, rapport, empathy, assertiveness without unnecessary confrontation, de-escalation techniques, scanning for potential problems and role-play. The private-investigator syllabus uses similar communication and de-escalation requirements.

The Canadian Police Knowledge Network's current Crisis Intervention and De-escalation course is a useful professional benchmark: it uses a four-phase model and emphasizes risk assessment, persons in crisis, mental-health context and scenario application. It is BC-policing-specific and should not be copied as an Ontario civilian course, but it confirms the learning shape: **de-escalation requires scenario practice, not a fact deck**.

### G. De-escalation I — communication fundamentals

**Completion claim**

> Can identify and apply core de-escalation communication principles in authored low- and moderate-intensity conflict scenarios.

Knowledge layer:

- maintain composure;
- use clear, concise language;
- avoid antagonistic or humiliating phrasing;
- adapt tone, volume and cadence;
- recognize that posture, distance, facial expression and eye contact affect communication;
- listen before problem-solving;
- acknowledge emotion without endorsing inaccurate claims;
- ask rather than assume;
- preserve dignity;
- recognize when disengagement or help is more appropriate than continued persuasion.

**Practice design**

The app shows a short interaction and asks the learner to select or compose the next response. Evaluation should explain which principle the response supports or violates.

This is much more valuable than memorizing an acronym alone.

### H. Crisis active listening — FBI ALS

The FBI Crisis Negotiation Unit has used active listening as a core crisis-negotiation technique for decades. FBI materials identify eight techniques:

- emotion labeling;
- paraphrasing;
- reflecting/mirroring;
- effective pauses;
- minimal encouragers;
- “I” messages;
- summarization;
- open-ended questions/statements.

These are highly practiceable and generalize beyond hostage incidents.

**Completion claim**

> Can identify the eight FBI crisis active-listening techniques and select or construct appropriate examples in authored scenarios.

The app should use transcripts rather than flashcards wherever possible.

Example practice types:

- identify which ALS technique a response uses;
- improve a weak response;
- choose between advice-giving and reflective listening;
- label emotion without claiming mind-reading;
- distinguish an open question from a disguised accusation;
- summarize content and emotion together.

### I. Behavioural Influence Stairway

The FBI's Behavioral Influence Stairway places active listening first, followed by empathy, rapport, influence and behavioural change.

This is a strong companion to OODA because it is a **process model** rather than a vocabulary set.

**Completion claim**

> Can recall the stairway sequence and identify why attempts to influence behaviour before listening, empathy and rapport are usually premature.

This is small enough for an ordinary topic, but it becomes significantly better when embedded in the crisis-communication curriculum.

### J. Motivational interviewing — OARS

SAMHSA's motivational-interviewing guidance defines OARS as open questions, affirmations, reflective listening and summarization.

This is not crisis negotiation, but it is a valuable general behavioural skill for consulting, coaching, conflict and change conversations.

**Completion claim**

> Can distinguish and apply OARS communication skills in authored non-clinical conversations.

This is probably a second-wave psychology course rather than an immediate field-safety course.

# 5. Psychological support without amateur diagnosis

The user's interest in “psychological evaluation” should be redirected toward **structured observation and support**, not diagnosing strangers.

A practical civilian learner can become better at:

- recognizing distress;
- listening without assumption;
- identifying when a situation exceeds ordinary peer support;
- linking a person to appropriate help;
- avoiding stigmatizing or unsupported diagnostic labels.

### K. Psychological First Aid — Look, Listen, Link, Live

The Canadian Red Cross currently teaches the Look, Listen, Link, Live model in its Psychological First Aid program. The formal course uses case-based learning and distinguishes PFA from mental-health emergency training.

That makes it particularly well suited to an Argus **companion** topic.

**Completion claim**

> Can recall the Red Cross Look, Listen, Link, Live framework and apply its high-level support principles in authored non-emergency scenarios.

**Important product boundary**

Argus should encourage the actual Canadian Red Cross course for anyone who wants training/certification. App completion is not Red Cross certification.

### L. Distress observation, not mental-status diagnosis

A possible later module could teach a bounded observation vocabulary:

- visible distress;
- marked change from known baseline;
- confusion/disorientation;
- agitation;
- withdrawal;
- communication difficulty;
- direct statements of harm or inability to cope.

But it should **not** teach a lay user to label psychosis, mania, personality disorders, schizophrenia, intoxication, or other diagnoses from appearance or behaviour.

That is both scientifically weak and potentially harmful.

# 6. Interviewing, memory and credibility

This is another rich Ontario-localized lane.

The current Ontario private-investigator syllabus explicitly includes narrative versus cognitive interviews, note-taking, statement protocols, communication theory, credibility/reliability assessment and role-play.

### M. Interviewing I — obtain information without contaminating it

**Completion claim**

> Can conduct the opening structure of a cooperative information-gathering interview using preparation, uninterrupted narrative, neutral follow-up questions and prompt objective notes.

This course can teach:

- define the information goal before the interview;
- begin with open narrative rather than leading detail;
- avoid unnecessary interruption;
- separate what the witness said from what the interviewer inferred;
- follow broad questions with specific clarification;
- document promptly;
- distinguish interview from interrogation.

Scenario practice can use short witness transcripts and ask which question should come next.

### N. Witness memory and cognitive-interview concepts

The cognitive interview is explicitly named in Ontario's PI training. A future course should research the evidence base in more depth before authoring, but the topic has strong potential because it connects psychology, memory and practical interviewing.

The likely Argus boundary is not “perform the full cognitive interview.” It is narrower:

> Can explain the core principles that reduce unnecessary memory contamination and support fuller witness recall.

This deserves a dedicated evidence review before implementation.

### O. Credibility and deception — what **not** to infer

This is a valuable corrective course.

People commonly overestimate their ability to detect lying from eye contact, fidgeting, nervousness or confidence. The APA's current polygraph summary likewise notes that scientific evidence does not support polygraph testing as a reliable and valid general deception detector.

An Argus topic could teach:

- credibility is not the same as confidence;
- anxiety is not proof of deception;
- no single body-language cue establishes lying;
- inconsistency can have many causes, including memory limitations;
- separate evidence quality from personal impression;
- seek corroboration rather than “reading” a person.

**Completion claim**

> Can identify common deception-detection errors and choose evidence-seeking responses over unsupported behavioural conclusions.

This would directly improve the threat-assessment courses by reducing overconfidence.

# 7. Evidence and field documentation

### P. Evidence continuity — Ontario six-step memory aid

Ontario's PI syllabus gives a compact six-step sequence for containing evidence:

- collect;
- secure;
- preserve;
- identify;
- continuity;
- log.

This is exactly the kind of finite list that belongs in Argus because it supports a broader field skill rather than existing as trivia.

**Completion claim**

> Can recall the Ontario PI syllabus's six evidence-containment steps in order and explain the purpose of continuity/documentation at a high level.

The app should not teach forensic collection techniques that require specialist training.

# 8. Firearms: what belongs and what does not

This lane should be explicitly **Canada-first** and anchored to current official materials.

## 8.1 Appropriate Argus scope

Suitable topics include:

### Q. Canadian firearm safety — ACTS

**Completion claim**

> Can recall and explain the four ACTS safety rules used in the Canadian Firearms Safety Course.

### R. Canadian firearm safety — PROVE

**Completion claim**

> Can recall the five PROVE safety steps and their order as taught in the Canadian Firearms Safety Course.

### S. Federal storage and transportation essentials

**Completion claim**

> Can recall the current federal storage and transportation requirements explicitly covered by the topic for the named firearm category and source version.

This content must be versioned and re-reviewed when federal regulations change.

### T. Canadian self-defence legal framework — Criminal Code s.34

**Completion claim**

> Can identify the three-part statutory structure of self-defence under Criminal Code s.34 and the principal reasonableness factors listed in the section.

This is legal literacy, not a decision algorithm for when to use force.

## 8.2 Out of scope for Argus

Do not use the app to teach or rehearse:

- tactical weapon employment;
- marksmanship drills;
- clearing buildings or rooms;
- engagement tactics;
- target-selection logic;
- combat techniques;
- weapon modification;
- methods intended to increase lethality.

Hands-on firearm competence belongs in the CFSC/CRFSC, supervised range instruction and other lawful formal training.

# 9. Proposed learning architecture: authored scenario practice

The field/human-skills portfolio reveals a stronger next product primitive than another flashcard format.

## 9.1 Generic scenario object

A future architecture issue should investigate a deterministic authored scenario model with fields conceptually like:

```ts
Scenario {
  id
  setup
  observations[]
  prompt
  options[]
  preferredResponses[]
  rationale
  sourceRefs[]
  tags[]
}
```

This is deliberately schematic, not a schema decision.

## 9.2 Four scenario forms

### Classification

Example:

> Which statement is an observation rather than an inference?

### Next response

Example:

> Which response best demonstrates reflective listening without agreeing with the claim?

### Information gap

Example:

> What additional information would most reduce uncertainty before escalating this situation?

### Rewrite

Example:

> Rewrite this incident note so it separates observation from conclusion.

## 9.3 Evidence semantics

Scenario practice should initially be **formative**, not equivalent to real-world competence.

A learner can earn evidence for knowledge/application inside authored scenarios. The permanent completion claim must still say exactly what was tested.

Do not infer “street competence,” “negotiator competence,” “investigator competence,” or firearm competence from app performance.

# 10. Recommended practical-skills programme

The first coherent practical-skills sequence should be:

1. **Situational awareness I — baseline, anomaly, reassess**
2. **Observation versus inference**
3. **De-escalation I — communication fundamentals**
4. **Crisis active listening — FBI ALS**
5. **Threat recognition I — concern, context, escalation**
6. **Bias control in behavioural judgement**
7. **Psychological First Aid — Look, Listen, Link, Live**
8. **Interviewing I — cooperative information gathering**

This sequence has a useful progression:

> observe accurately → interpret conservatively → communicate effectively → detect escalating concern → reduce judgement error → support → gather information.

It creates materially different competence from the current symbol/mapping topics.

The firearm lane should be a separate later companion set:

1. ACTS;
2. PROVE;
3. federal storage/transport essentials;
4. Criminal Code s.34 structure.
