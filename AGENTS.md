# Repository agent guidance

## Documentation housekeeping

Keep repository documentation under `docs/open/` or `docs/closed/`.

- `docs/open/` is for current product, architecture, implementation, and decision documents, including maintained contracts for shipped behavior.
- `docs/closed/` is for completed closeouts, historical research, and superseded proposals retained for rationale or provenance.
- When a workstream is completed or superseded, move its document to `docs/closed/` and update every repository link.
- When creating or editing a document, keep its status and authority banner accurate.
- Use `docs/README.md` for the lifecycle definition and index the documents from `README.md` when they are user-facing repository guidance.
