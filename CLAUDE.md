# Repository guidance

Follow `AGENTS.md` for repository-wide conventions. In particular, keep documentation organized under `docs/open/` and `docs/closed/`, update links when documents move, and keep status or authority banners accurate. See `docs/README.md` for the lifecycle rule.

For shipped Library topic icon work, follow `docs/open/LIBRARY_TOPIC_ICONS.md` as the active visual and asset authority.
